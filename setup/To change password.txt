To change the password:
If you want to use a different password (recommended for security), simply replace '1' with your desired password in that line.

For example, to set the password to StrongPass123!:

```sql
CREATE USER 'forrest'@'localhost' IDENTIFIED WITH mysql_native_password BY 'StrongPass123!';
```
Important security note:
The password to 1 is an extremely weak password. I recommend using a stronger password for any real-world application:

```bash
# Change password after installation:
mysql -u root -pnew_strong_root_password -e "ALTER USER 'forrest'@'localhost' IDENTIFIED BY 'StrongerPassword123!';"
```

Then update your vt_setting.json accordingly:

```json
"database.password": "StrongerPassword123!"
```
